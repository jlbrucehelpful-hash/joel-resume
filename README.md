# Joel Bruce - IT & EUC portfolio

A dependency-free professional resume and portfolio website for enterprise IT support, EUC, endpoint operations, Microsoft 365, automation, and selected technical projects.

Main is the primary IT job-market version. It keeps Level 2 Desktop Support and endpoint work first, with Context Mesh, Transcription Lab, and Endpoint Automation Toolkit as focused current-project evidence. Role-fit evidence appears in Professional Profile before the project section.

Open `index.html` directly, or run `dev-server.ps1` for local development. Content is maintained in `content.js` and `projects-data.js`; page structure is in `index.html` and `projects.html`; styling is in `styles.css` and `resume.css`.

The repository also includes a print-friendly portfolio view at `portfolio-pdf.html`. Main is published from the `main` branch through GitHub Pages after an approved push.
