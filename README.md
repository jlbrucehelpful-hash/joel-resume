# Joel Bruce - AI-enabled IT portfolio

A dependency-free AI-forward companion version of Joel Bruce's professional portfolio and resume website. It presents enterprise IT support alongside AI-assisted build work, automation, MCP, endpoint tooling, and workflow design.

Noddy is the experimental and targeted-sharing version; Main remains the primary IT job-market version. The visible project catalogue focuses on Context Mesh, Transcription Lab, AI Automation Agent, Endpoint Automation Toolkit, and the AI-assisted portfolio website. Role-fit evidence appears in Professional Profile before the project section.

Open `index.html` directly, or run `dev-server.ps1` for local development. Content is maintained in `content.js` and `projects-data.js`; page structure is in `index.html` and `projects.html`; styling is in `styles.css` and `resume.css`.

The repository also includes a print-friendly portfolio view at `portfolio-pdf.html`. Keep personal profile drafts, local runtime data, and other planning notes outside this public repository. Pushing Noddy updates its branch; it does not change Main's GitHub Pages site.
